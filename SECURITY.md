## Reporting a Vulnerability

We take the security of Cue seriously. If you discover a security vulnerability, we would appreciate it if you could report it privately so it can be fixed before being publicly disclosed.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to: **lz00qs@gmail.com**

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

When reporting a vulnerability, please try to provide a detailed description of the issue, the steps to reproduce it, and any potential impact. We will work with you to understand and resolve the issue quickly and securely.
